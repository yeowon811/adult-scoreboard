📊 실시간 현황 모니터링 (사용자 화면 동기화 중)

🎮 게임별 점수 입력표

* 칸에 점수를 입력하면 조별 총점(게임 + 공통미션 + WALL STREET)이 자동으로 합산·동기화됩니다. (빈 칸 = 미입력)
* Enter: 아래 칸 / Shift+Enter: 위 칸 이동

🤝 공통미션별 점수 입력표

* 공통미션 점수도 게임 점수와 함께 조별 총점에 합산되고, 현황판(user)에 따로 표시됩니다.
* 감점은 음수(예: -30)로 입력하세요. Enter: 아래 칸 / Shift+Enter: 위 칸 이동

💹 WALL STREET 점수 입력표

* WALL STREET 점수도 게임·공통미션 점수와 함께 조별 총점에 합산되고, 현황판(user)에 따로 표시됩니다.
* 감점은 음수(예: -30)로 입력하세요. Enter: 아래 칸 / Shift+Enter: 위 칸 이동

👔 부장 아이템 & 💸 투자내역

* 부장이 누른 아이템(손실방어 / x2 / x3)을 초기화하면 해당 조가 다시 사용할 수 있습니다.
* 투자내역은 왼쪽에서 이익 / 손실을 고르고 금액을 입력하세요. 총 금액(이익 − 손실)이 위에 표시되고, 해당 조 부장 화면에도 바로 표시됩니다.

📩 조별 점수/값 제보 (타임라인)

* 실시간 점수 현황판에서 각 조가 보낸 제보(부장 아이템 사용 등)가 받은 순서대로 표시됩니다.

조(팀) 관리

* 조마다 비밀번호 2개: 조원 비밀번호(일반 조원 입장) / 👔 부장 비밀번호(해당 조 부장 입장). 모든 비밀번호는 서로 겹치지 않아야 합니다.

조 이름 조원 비밀번호 👔 부장 비밀번호 총점 관리

📈 조별 점수 변동 추이 (꺾은선 그래프)

* 시작을 누르면 점수 입력값·투자내역·부장 아이템·제보 타임라인이 모두 초기화되어 모든 조가 0점에서 출발하고, 종료를 누를 때까지 10분마다 현재 총점이 그래프에 자동으로 이어서 기록됩니다.
* 10분 기록은 관리자 화면이 열려 있을 때 저장됩니다. (화면을 닫아두었던 구간은 다시 열었을 때 그 시점 점수로 1개만 기록)
* 종료 후 💸 투자내역 반영을 누르면 마지막 지점 점수에 각 조 투자 총 금액(이익 − 손실)을 더한 지점이 그래프 맨 끝에 추가됩니다. (그래프에만 표시, 총점은 그대로)
